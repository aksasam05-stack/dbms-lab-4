## About the Project

RG Canteen is a web-based canteen management system developed to make food ordering easier for students and staff.

The system allows users to browse food items, select quantities, add items to their cart and proceed to checkout. It also provides an owner login and dashboard to manage canteen orders.

## Technologies Used

- **HTML** – Structure of web pages.
- **CSS** – Styling and page design.
- **PHP** – Server-side processing and session management.
- **MySQL** – Database management and storage.

## Main Features

- Food menu with categories.
- Add, update and remove cart items.
- Shopping cart with automatic total calculation.
- Checkout system.
- Owner login and authentication.
- Owner dashboard.
- Order report.
